# policy-manifest.txt
#
# The canonical Claude-policy files this starter kit owns and propagates to
# downstream repos. This kit is the single upstream source of truth for these
# paths: change them HERE first, then run `scripts/sync-policy.sh <repo>` to
# open a reviewed sync PR in each downstream repo.
#
# Format: one repo-relative path per line. Blank lines and `#` comments ignored.
#
# RULE OF THUMB: a file belongs here only if it is meant to be byte-identical in
# every repo (a generic mechanism or generic guidance). Anything a project
# customizes (path maps, project-specific agents/rules, project docs) is
# PROJECT-OWNED and must NOT be listed — see the excluded list at the bottom.
