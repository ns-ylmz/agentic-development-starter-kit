## Antigravity (AGY) / Gemini Operating Notes

This repo wires the following Antigravity mechanisms on top of the tool-agnostic guidance in `AGENTS.md` and `.ai/`. The actual logic and knowledge live in `.ai/`; everything under `.agents/` is a thin, Gemini-specific pointer to it. Keep it that way when adding more.

- **Hooks** (`.agents/hooks.json`): `PreToolUse` on `run_command` runs `.ai/hooks/guard-git.sh` — blocks commits on `main`/`master`, force-push, and staged secret/env files. `PreToolUse` on `run_command` also runs `.ai/hooks/guard-pr-body.sh` — blocks PR creation unless the body follows `.github/pull_request_template.md`. `PostToolUse` on `write_to_file|replace_file_content` runs `.ai/hooks/post-edit-verify.sh` — surfaces eslint output for the file just touched. `PostToolUse` on `run_command` runs `.ai/hooks/suggest-branch-cleanup.sh` — after `git checkout main`, reminds (non-blocking) to check for mergeable local branches. `PostToolUse` on `mcp_.*pull_request_create` runs `.ai/hooks/remind-return-to-main.sh`. `PreToolUse` on `replace_file_content|write_to_file` runs `.ai/hooks/guard-domain-boundary.sh` — when the active subagent is `backend-implementer` or `frontend-implementer`, blocks it from editing the other app's `apps/<side>/**` files.
- **Skills** (`.agents/skills/*/SKILL.md`): `backend-implementation`, `frontend-implementation`, `shared-implementation`, `refactor`, `add-tests`, `update-docs`, `bugfix`, `architecture-review`, `execute-task` — each wraps the matching section of `.ai/prompt-templates.md`.
- **Rules** (`.agents/rules/*.md`): path-scoped auto-loading. `apps/backend/**` loads `.ai/backend-domain-boundaries.md` and `.ai/backend-testing-patterns.md`; `apps/frontend/**` loads the frontend equivalents; `packages/shared/**` loads `.ai/shared-domain-boundaries.md`.
- **Subagents** (`.agents/agents/*.md`): `backend-implementer` and `frontend-implementer` mirror the matching skill's prompt template, but run in their own isolated context.
